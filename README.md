# Calculadora La Solución

Aplicación web desarrollada con Python y Streamlit para resolver operaciones matemáticas básicas y ejercicios de Cálculo I.

## Funcionalidades

✅ Suma, resta, multiplicación y división  
✅ Derivadas, integrales, límites y evaluación de funciones  
✅ Entrada por texto y por voz  
✅ Resultado mostrado y leído en voz alta  
✅ Explicaciones paso a paso  
✅ Opción para imprimir resultados

## Requisitos

Instalar las dependencias:
```
pip install -r requirements.txt
```

## Ejecución local

```
streamlit run calculadora_la_solucion_mejorada.py
```

## Despliegue en Streamlit Cloud

Sube este repositorio a GitHub y usa como:
- Archivo principal: `calculadora_la_solucion_mejorada.py`
- Rama principal: `main`
